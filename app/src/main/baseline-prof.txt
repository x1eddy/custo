# Baseline profile for Custo (hand-written).
#
# ART compiles these classes/methods ahead of time when the app is installed (profileinstaller
# writes the profile for sideloaded builds; background dexopt or `cmd package compile -m speed-profile`
# applies it). That removes JIT warm-up from cold start, the first visit to every tab, scrolling
# the galleries and the off-thread preview renderers.
#
# Flags: H = hot, S = startup, P = post-startup. `**` matches anything. R8 rewrites the names.
